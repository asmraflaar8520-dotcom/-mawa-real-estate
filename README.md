## 🏛️ عن المنظومة (Project Vision & Core Principles)

**مأوى (MA'WA)** هي منصة عقارية مصرية مبنية وفق أعلى المعايير الهندسية ومعايير الأمن السيبراني المتقدمة (Clean Modular Monolith)، تهدف إلى إعادة الانضباط والشفافية لسوق العقارات بمحافظة الغربية من خلال:

1. **فصل نماذج التوثيق (Separated Verification Model):**
   - استقلالية كاملة بين توثيق هوية المستخدم الشخصية (`IdentityStatus`)، والاعتماد المهني للوسيط (`ProfessionalStatus`)، وموقف ترخيص البناء للعقار (`BuildingLicenseStatus`).
   - لا يمنح تسجيل حساب الوسيط شارة الاعتماد تلقائياً إلا بعد فحص أوراقه من الإدارة.
2. **حماية الخصوصية الجغرافية (Location Privacy-by-Design):**
   - حجب العنوان التفصيلي الدقيق (`exact_address_private`) والإحداثيات الحرجة عن الواجهات العامة، والاكتفاء بالإحداثيات التقريبية والحي، ولا يُكشف العنوان إلا بعد قبول طلب المعاينة بالتراضي.
3. **عزل مستندات الهوية (Zero Public Access for Sensitive Docs):**
   - حفظ بطاقات الرقم القومي والسجلات التجارية في مسار معزول `storage/private_docs/` بأسماء عشوائية `UUID`، مع منع أي مسار عام لها وتسجيل كل استعراض إداري في سجل تدقيق محكم (`AuditLog`).
4. **المقارنة الفنية المحايدة (Neutral Fact-Based Comparison):**
   - جدول مقارنة فنية بين 2 إلى 4 عقارات يعتمد على الأرقام المجردة وسعر المتر الصافي وموقف التراخيص دون توجيه المستخدم أو تفضيل إعلان على آخر.
5. **فحص مأوى الذكي (MA'WA Check):**
   - قائمة تدقيق تفاعلية للمشتري تتضمن أهم 7 أسئلة قانونية وفنية قبل دفع أي مقدمات أو التوقيع.
6. **الحماية الصارمة من ثغرات BOLA / IDOR:**
   - تحقق خادمي صارم يمنع أي مستخدم من قراءة أو تعديل طلبات معاينة أو عقارات تخص مستخدمين آخرين.

## 🚀 التثبيت والتشغيل المحلي (Setup & Execution)

### 1. تثبيت الاعتمادات
```bash
cd mawa
pip install -r requirements.txt
```

### 2. إعداد المتغيرات البيئية
```bash
cp .env.example .env
```

### 3. بذر البيانات التجريبية لعقارات الغربية
```bash
python -m backend.app.utils.seed_data
```

### 4. تشغيل خادم التطوير
```bash
python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000
```
- المنصة والواجهة الرئيسية: `http://127.0.0.1:8000/`
- التوثيق التفاعلي للـ API (Swagger): `http://127.0.0.1:8000/docs`
